# ✅ Todo App – React

Aplicación web de lista de tareas desarrollada con **React**, pensada para practicar el manejo de estados, componentes reutilizables y buenas prácticas de Front-End.

---

## 🚀 Demo

https://todo-app-react-eight-chi.vercel.app

---

## 🛠️ Tecnologías utilizadas

- ⚛️ **React**
- 🟨 **JavaScript (ES6+)**
- 🎨 **CSS**
- ⚡ **Vite**
- 🌐 **HTML5**

---

## ✨ Funcionalidades

- ➕ Agregar nuevas tareas
- ✅ Marcar tareas como completadas
- 🗑️ Eliminar tareas
- 📋 Visualización clara de tareas pendientes y realizadas
- ♻️ Componentes reutilizables
- ⚙️ Manejo de estado con `useState`
